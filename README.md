# 财报查询台

一个本地运行的财经查询网站：前端使用 Vue 3 + TypeScript，后端使用 NestJS，财报数据通过 Python 调用 AKShare 获取。

## 功能

- 搜索 A 股和港股公司
- 拉取公司自上市年开始的全部年度财报，并保留最近 20 个季报/中报报告期
- 查看资产负债表、利润表、现金流量表
- 查看最新报告期累计同比、最近十二个月（TTM）指标和最近 8 期三表明细
- 自动校验三表完整度和关键勾稽关系，保留不可变财报版本并提示历史数据调整
- 首屏先给出可解释的研究结论、诊断维度和优先关注信号
- 分析盈利、现金质量、成长、偿债和营运效率指标，包括自由现金流、三年累计现金含金量、现金循环周期及增长背离预警
- 拆解杜邦 ROE、利润到自由现金流和营运资本驱动
- 查看 ETF、主要指数、同行对比和估值数据，并显示个股在行业横截面中的相对位置
- 使用 ROA、PE、市值等条件筛选公司
- 查看最近 12 期单季／半年度经营变化，包括收入、归母／扣非利润、现金流和利润率；缺少必要前期数据时不估算
- 使用三情景 PE 终值估值，测算分红、股本变化、汇率、折现价值、IRR、敏感性和隐含增长率，并将假设保存为 SQLite 历史快照
- 保存收藏、结构化研究档案、买点区间并跟踪公告；公告默认突出重要事件并收起例行披露
- 财报首次拉取后写入本地 SQLite，后续默认直接读本地库
- 前端提供搜索结果栏、年度筛选、关键指标趋势和明细表格

## 持仓估值表

从顶部“持仓”进入，或打开 `http://localhost:3000/?view=portfolio`。搜索添加A股或港股（不支持B股），点击“编辑”填写当前持仓总市值、三年后估值、理想买点、1年内卖点和备注。持仓金额单位为元，添加港股默认港币，A股默认人民币，可手动切换；港币按页面查询的中间价折合人民币，持股比例自动按各家公司折合金额除以表内总金额计算。金额未填齐或缺少必要汇率时不显示比例；无持仓请明确填0。总金额为零时不计算比例。旧记录的手填比例不会被反推成金额，估值与备注保留，金额待补填。持仓金额不随股价自动变动，分母不含表外现金或资产；比例显示保留两位小数，可能有舍入差异。使用旧汇率时提示金额和比例为估算。估值及买卖点仍按公司总市值填写，单位为亿元人民币。三年后估值支持区间、±及文字；理想买点使用下限和上限两个非负数字（可含小数，下限不得大于上限，可同时留空），旧单值作为上下限相同的区间读取；1年内卖点仍为单个非负数字，历史文字值保留显示，编辑后保存需要改为数字。两列下方按「目标总估值÷当前人民币公司市值×当前股价」显示每股价格，买点分别显示下限和上限对应的每股价格，假设股本不变；港股结果为港币/股，缺少行情、汇率或数字目标时不估算。记录保存到本地SQLite。

三年后估值记录服务器填写时间，按北京时间自然年判断是否过期。进入新年时保留原值和原目标年份，标红“过期数据，需要更新”。修改仓位、买卖点、备注或刷新行情不改变估值时间；修改估值，或勾选“我已重新评估”后保存，才会更新填写时间和三年后目标年份。历史估值确认保存在独立记录中；编辑和删除均校验版本，防止多页面覆盖。

当前股价、原币总市值与沪深300点位来自腾讯证券；年内涨幅使用腾讯不复权日线的上年最后可用交易日收盘价计算，展示基准日期，不含分红。缺少上年基准（如年内新上市）、行情年份不符或请求失败时不补算、不填零。港股人民币市值按国家外汇管理局公布的港元兑人民币中间价换算，原港币市值同时保留。行情缓存3分钟，进入页面或点击“刷新行情”查询；失败保留上次成功快照并提示，数据源交易日期和获取时间分别显示。本表不计算实盘净值或组合回报。

持仓接口为 `GET/POST /api/portfolio`、`PUT/DELETE /api/portfolio/:id`，金额字段为 `holdingValue`（数字或null）、币种为 `holdingCurrency`（CNY/HKD，未指定时按市场默认：港股HKD、A股CNY）；行情接口为 `GET /api/portfolio/quote/:market/:symbol`。`node scripts/portfolio-smoke.mjs` 在独立数据库中验证金额币种保存、混合币种占比、汇率刷新及缺失、跨年提醒和手机布局，不修改日常持仓。

### 账户收益统计

持仓页的“收益统计”采用账户资产快照＋外部出入金流水，独立于持仓估值表。首次启用时将北京时间当天持久化为起算日；用户填写当天的起始账户净资产后才初始化基金净值1，不把持仓市值自动当成全部账户净资产。净资产包括全部持仓、现金并扣除负债，快照统一填人民币。

- 支持起始资产、资产快照、资金转入和资金取出，记录北京时间至分钟。同一时刻不允许重复记录，起始资产须唯一且为最早记录。可编辑、删除，历史修订保存为不可变版本，多页面旧版本写入会被拒绝。已有后续记录时不能删除起始资产。
- 基金净值法按转账前资产和当时单位净值增减份额，显示单位净值及累计收益率。转账前资产缺失、净值归零后追加资金等无法可靠计算的场景明确提示，不显示虚构收益。无外部现金流时无需逐笔录入股票买卖。
- XIRR使用起始资产/转入为负、取出/最后净资产为正，按实际日期差/365求解年化收益率。同日现金流合并；不足一天、无可靠解或检测到多解时留空说明。数值求解使用log(1+r)区间[-30,30]扫描及二分，区间外的极端收益可能无法求解。完全亏损且无回款时显示-100%。
- 港币流水需填写该笔当日汇率，折算值随记录保存；后续行情更新不重估历史。内部买卖、换汇、账户内分红和统计范围内账户互转不算出入金。用户须补齐完整流水，快照显示收益截止时刻，不宣称自动实时更新账户净资产。
- API为 `GET/POST /api/portfolio-performance`、`PUT/DELETE /api/portfolio-performance/:id`。表为 `portfolio_performance`、`portfolio_performance_history`。`node scripts/performance-smoke.mjs` 使用独立数据库验证初始化、现金流、币种换算、两种收益、编辑删除、缺失数据及手机布局，不修改日常账户。

## 技术结构

- `apps/web`: Vue 3 + TypeScript + Vite
- `apps/api`: NestJS API，托管生产构建后的前端静态文件
- `apps/api/src/python/akshare_bridge.py`: AKShare Python 适配器
- `data/finance.sqlite`: 本地财报数据库

NestJS 可以跑这个项目。AKShare 是 Python 库，所以这里采用 NestJS 调用 Python bridge 的方式，既保留 NestJS 的工程化能力，也不需要重写 AKShare 数据采集逻辑。

## 安装

```powershell
npm ci
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r apps/api/requirements.lock.txt
```

需要 Node.js 22.5 或更高版本，推荐 Python 3.12。`requirements.lock.txt`
用于复现当前已验证的 Python 环境；需要升级 AKShare 时再更新锁文件。

项目会优先使用根目录下的 `.venv\Scripts\python.exe`。如果本机 `python` 不是你要用的解释器，也可以在 `.env` 中设置：

```dotenv
PYTHON_BIN=C:\Python312\python.exe
```

## 配置

复制 `.env.example` 为 `.env` 后即可覆盖默认配置。服务和开发页面默认只监听本机回环地址；如需局域网访问，应显式设置 `HOST`、`WEB_ORIGIN`，并自行增加身份认证。

常用配置：

- `HOST`、`PORT`：API 监听地址和端口。
- `WEB_ORIGIN`：允许的前端来源，多个来源用逗号分隔。
- `AKSHARE_TIMEOUT_MS`：单个 Python 数据任务的总超时。
- `AKSHARE_MAX_OUTPUT_BYTES`：Python bridge 单次允许返回的最大数据量。
- `AKSHARE_EXPOSE_ERROR_DETAILS`：是否向浏览器暴露上游错误细节，默认关闭。
- `FINANCE_DB_PATH`：SQLite 数据库路径。
- `FINANCE_REFRESH_*`、`ANNOUNCEMENT_*`：后台刷新频率。
- `REQUEST_ERROR_LOG_*`：异常请求日志的启用状态、目录、保留天数和清理周期。日志默认写入 `data/logs`，保留 14 天并每 24 小时清理一次。

## 经营变化与情景估值口径

- 年度质量结论明确标注年度，最新年度缺失不回填往年指标；无风险标签需覆盖该诊断至少 80% 的指标。
- 资本开支优先使用合计项；只有分项齐全时才加总，现金流指标和驱动面板共用计算逻辑。
- 单季使用同财年累计差额，资产负债表不差分。港股依靠 `START_DATE` 判断期间，支持非自然年度及半年披露；旧缓存缺少该字段时请刷新。
- 财报保留报告币种、金额倍率和财年起始日期。港股接口未提供的币种／倍率显示为未确认，不按上市地推断，不自动换汇。旧缓存没有新增元数据时需刷新或手工核对。
- 估值输入金额为报告币种的亿元、总股本为亿股。自动导入仅在财报币种和金额倍率已确认时启用；不会把合并净利润替换为归母净利润。
- 三情景支持 3／5 年预测。每年末分红和期末出售价格折现为当前每股价值，IRR按各期现金流求解；税费、汇率未来变化和回购资金约束不自动预测。
- 保存估值需要明确期间、口径、来源与三种情景依据。每次保存新增不可变快照，界面展示最近 30 份；财报版本变化时提示重新核对。

## 分业务经营数据与研究假设

- A股公司研究页面会自动抓取东方财富主营构成，覆盖接口提供的历史行业、产品和地区拆分，以及收入、成本、主营利润、毛利率和源披露收入占比。24小时内使用本地同步结果，也可点击“刷新自动业务数据”。失败保留原记录，自动重试间隔至少5分钟，手动刷新可立即重试。港股暂未接入可靠的结构化分部源；渠道、销量等未覆盖指标仍可手工补录。
- 自动记录保留来源链接、抓取时间、原始字段、原始数值／单位和完整源行，可展开“原始证据”核对。来源是东方财富的二次整理，并非直接解析原报告；数据源未提供原报告页码，不编造页码。金额按该A股接口人民币元口径换算为亿元，比例由小数转百分数，期间按自然年年初累计；分部重分类、内部交易和追溯重述仍需查原报告。保留“主营利润”原字段名称，不将其视为营业利润。适配依据：[AKShare主营构成接口文档](https://akshare.akfamily.xyz/data/stock/stock.html)及其公开源接口。
- 自动刷新按稳定记录身份去重，仅在数值或证据变更时新增版本；人工编辑、归档的记录及已有同口径手工记录受保护，不被覆盖。源中消失的自动记录保留并标记待核对，不再参与比较和假设验证；空返回或抓取失败不会清空记录。
- 手工补录支持业务、产品、地区、渠道及公司整体，注明期间、单位、币种、统计口径、报告来源、链接和页码。金额单位为元／万元／亿元时必须填写币种；实际值默认留空，避免把缺失误当作零。
- 同比只匹配上年相同期间及一致的指标、单位、币种和口径；非正基数不计算增长率，百分比指标显示百分点变化。占比需要另外录入公司整体值，不把不完整或重叠的分部相加为总额；毛利率需要同口径营业收入及毛利。
- 点击业务记录的“建立假设”，可填写未来目标期间、预期上下限（含边界）、验证日期、理由，并关联该公司的估值快照。也可独立新建假设。刚保存的估值快照可通过“重新载入研究记录与估值快照”载入。
- 实际数据必须与假设的业务、指标、期间、单位、币种和统计口径完全一致才参与验证。页面标出待验证、到期、达标、偏离或修订后需重验；保存验证时需要填写结论及估值影响，不自动改写估值模型。到期提示仅在页面内显示。
- 业务数据、假设和验证记录均存入 SQLite，按公司隔离；每次修改保留不可变历史版本。验证冻结当时的实际值与数据版本，后续修订提示重验。归档可恢复；编辑或恢复假设需要重新验证。多页面同时修改时拒绝覆盖旧版本，需重新载入核对。

代码评审还应遵守 [PROJECT_NOTES.md](./PROJECT_NOTES.md#file-size-and-responsibility-guardrails) 中的文件规模与职责边界约束，避免应用外壳、存储门面和命令入口再次膨胀成巨型文件。

## API

- `GET /api/health`
- `GET /api/companies/search?q=腾讯&market=all`
- `GET /api/finance/statements?market=hk&symbol=00700`
- `GET /api/finance/statements?market=a&symbol=600519`
- `GET /api/finance/statements?market=hk&symbol=00700&refresh=true` 强制重新拉取并更新 SQLite
- `GET /api/cache/stats` 查看本地库统计
- `GET /api/finance/research/:market/:symbol` 读取业务与假设记录
- `POST /api/finance/research/:market/:symbol/business-sync?refresh=false` 自动同步业务数据，返回记录和同步状态；refresh=true 强制刷新
- `POST /api/finance/research/:market/:symbol/business`、`PUT .../business/:id` 新增／修改业务数据
- `POST /api/finance/research/:market/:symbol/hypotheses`、`PUT .../hypotheses/:id` 新增／修改假设
- `POST /api/finance/research/:market/:symbol/hypotheses/:id/review` 保存验证与估值影响
- `GET /api/finance/research/:market/:symbol/:kind/:id/history` 读取历史版本，kind 为 business 或 hypotheses

## 本地 SQLite 缓存

数据库位置默认是：

```text
data\finance.sqlite
```

写入策略：

- 后端先按 `market + symbol + years` 查询 SQLite。
- 命中缓存时直接返回本地 JSON，避免重复请求 AKShare。
- 未命中时调用 AKShare，成功后同时写入完整响应和拆分后的明细表。
- 点击前端“刷新”会带上 `refresh=true`，强制重新拉取并覆盖本地快照。

为后续搜索和图表预留的表：

- `companies`: 公司代码、名称、市场，供本地搜索使用。
- `financial_statement_cache`: 标准化后的完整财报响应，供页面快速返回。
- `financial_statement_rows`: 报表行项目，供按科目搜索。
- `financial_statement_values`: 年份维度的明细值，供多公司/多指标图表。
- `financial_metric_values`: 总资产、总负债、营业收入、净利润、经营现金流等关键指标序列。
